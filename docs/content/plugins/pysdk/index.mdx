# pysdk

byk python 插件开发套件，以两个独立 `.py` 文件分发。无框架约束，纯函数调用，按需取用。

## 安装

```bash
byk add fcbyk/byk/plugins/pysdk
```

从仓库的 `plugins/` 多级目录拉取 `pysdk.byk.json`，把两个 `.py` 文件下载到当前工作目录（多文件归入 `assets/` 子目录）：

| 文件 | 内容 |
|------|------|
| `byksdk.py` | 插件上下文、StateStore、路径常量、日志（纯标准库） |
| `utils.py` | 网络检测、CLI 输出、Web 辅助函数 |

这就是普通的 `.py` 文件，**用不到的函数可以直接删除**，没有任何隐藏依赖。

`utils.py` 依赖的第三方库（psutil、click、pyperclip、flask）需自行安装，下载的文件位置也可按需调整后再 import。
