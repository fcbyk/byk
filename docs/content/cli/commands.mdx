# 内置命令

byk 提供一组内置子命令，用于添加功能、管理插件、生成补全脚本等。运行 `byk -h` 或不带任何参数即可看到帮助信息。

## add

安装插件（远程 `*.byk.json` / 本地）或初始化内置功能（comp）。

```bash
byk add [OPTIONS] <user/repo[/path]> | <file> | FEATURE
```

### 插件安装 (Plugins)

| 选项 | 说明 |
|------|------|
| `-f, --file <PATH>` | 安装指定路径的本地 `.byk.json` 文件 |
| `--cdn` | 通过 jsDelivr CDN 访问 GitHub 仓库 |

三种安装来源：

- **远程**：`byk add user/repo/path` 从 GitHub 仓库拉取 `path.byk.json`（支持多级目录）；`repo@branch` 指定分支/tag
- **本地文件名**：`byk add myfile` 安装当前目录的 `myfile.byk.json`
- **本地路径**：`byk add -f ./path/to/x.byk.json`

```bash title="示例"
byk add user/repo/pysdk        # 拉取 pysdk.byk.json
byk add user/repo/tools/lint   # 拉取 tools/lint.byk.json（多级目录）
byk add user/repo@dev/hello    # 从 dev 分支拉取 hello.byk.json
byk add --cdn user/repo/hello  # 走 jsDelivr CDN
byk add myfile                 # 安装当前目录 myfile.byk.json
byk add -f ./path/x.byk.json   # 安装指定路径的本地文件
```

安装 = 装 `$pip`/`$pip-keep` + 下载 `$assets` + 写副本到 `~/.byk/alias/<file>.byk.json`（文件级字段 + 全部别名）。仅 `$plugin: true` 的文件可被安装。

:::tip
远程包的 `$assets` 相对路径解析成**相对 URL**（相对仓库内文件目录）；本地文件则解析成相对文件目录的本地路径。详见 [别名配置 - 资源下载](/cli/alias/config)。
:::

### 功能 (Features)

| Feature | 说明 |
|---------|------|
| `comp` | 初始化 shell 补全（自动检测 zsh/bash），在对应 rc 文件中追加补全脚本 |
| `pip <@file\|@@file\|PATH>` | 安装别名文件 `$pip` 声明的 Python 依赖到 byk 托管 venv |
| `assets <@file\|@@file>` | 拉取别名文件 `$assets` 声明的资源（URL/本地路径/解压/可执行位） |

```bash title="示例"
byk add comp      # 配置 shell 补全
byk add pip @jiahao   # 安装 jiahao.byk.json 的 $pip 依赖
byk add assets @demo  # 拉取 demo.byk.json 的 $assets 资源
```

:::tip
`byk add pip` 的 target 支持三种形态：`@file`（当前目录）、`@@file`（全局目录 `~/.byk/alias/`）、`.byk.json` 路径。venv 不存在时按需创建（uv 优先，一次性确认）。详见 [别名配置 - Python 依赖](/cli/alias/config)。
:::

:::tip
`byk add assets` 的 target 支持 `@file`（当前目录）、`@@file`（全局目录）两种形态（资源目录需要文件 key）。支持 `--cdn`（GitHub raw 走 jsDelivr）。详见 [别名配置 - 资源下载](/cli/alias/config)。
:::

:::note
`byk add comp` 是幂等的——已配置过补全时会跳过，不会重复追加。
:::

## remove

移除已初始化的功能或卸载插件。

```bash
byk remove <feature>
```

| Feature | 说明 |
|---------|------|
| `comp` | 移除 shell 补全配置（从 .zshrc / .bashrc 中删除相关行） |
| `all` | 移除所有持久化数据（`~/.byk/` 和 shell 补全），需输入确认 |
| `<plugin-key>` | 卸载指定插件（删除脚本文件并清除命令缓存，不卸载 pip 包） |

```bash title="示例"
byk remove comp        # 移除 shell 补全
byk remove hello       # 卸载名为 hello 的插件
byk remove all         # 清除所有数据
```

:::note
如果当前运行的 byk 二进制文件位于 `~/.byk/` 下（如通过 curl 脚本安装），`remove all` 会跳过自身所在目录，并提示手动删除。
:::

## completion

生成指定 shell 的补全脚本并输出到 stdout。通常由 `byk add comp` 自动调用，无需手动使用。

```bash
byk completion <shell>
```

支持的 shell：`zsh`、`bash`、`fish`。

```bash title="手动配置补全"
# zsh
source <(byk completion zsh)

# bash
source <(byk completion bash)

# fish
byk completion fish | source
```

## 全局选项

| 选项 | 说明 |
|------|------|
| `-v, --version` | 打印版本号、构建信息及安装路径 |
| `-h, --help` | 打印帮助信息（含 Commands、Aliases 一览） |

## show

查看系统信息、插件列表或命令来源。

```bash
byk show [SUBCOMMAND]
```

| Subcommand | 说明 |
|------------|------|
| `overview` | 总览面板：目录路径、补全状态、Python |
| `plugins` | 已安装插件列表及其命令和脚本 |
| `<command-name>` | 命令名全量路由查询（查找内置命令、插件、别名中的所有匹配） |

不带子命令时显示帮助信息。

```bash title="示例"
byk show                     # 显示帮助信息
byk show overview            # 系统总览面板
byk show plugins             # 已安装插件列表
byk show build               # 查询 "build" 命令的所有来源
```

```bash title="命令名查询示例"
byk show build
# 输出所有名为 "build" 的命令来源：
# Built-in / Plugin / Alias（含优先级、模板、占位符等详情）
```

## 命令执行优先级

当输入 `byk <name>` 时，byk 按以下顺序匹配命令：

1. **内置子命令** — `add`、`remove`、`completion`、`show`
2. **全局选项** — `-v`、`-h`
3. **插件命令** — 通过 `byk add` 安装的插件
4. **精确执行语法** — `@file.key`（本地）/ `@@file.key`（全局）
5. **别名** — 从 `*.byk.json` 文件中加载的别名

匹配到第一个命中即执行，不会继续向下查找。
