# 选项与命令

byk 的命令行只有三层：**选项**、**别名**、**程序接口**。没有子命令，`add` / `remove` / `show` 这些词全部空出来，你想用就可以当别名用。

```
Usage: byk [OPTIONS] [ALIAS] [ARGS]...
```

## 选项

| 选项 | 说明 |
|------|------|
| `-h, --help` | 帮助：banner + Usage + Options + 全部别名 |
| `-v, --version` | 版本、构建信息与安装路径 |
| `--paths` | 打印 CLI 用到的目录位置 |

`byk` 不带参数与 `byk -h` 输出完全一致。第一行固定为 `byk <版本> (<commit> <构建日期>) [<平台>]`，可以安全地用 `byk -v | head -1` 取版本号。

```bash title="-v"
$ byk -v
byk 0.5.1 (51ba30b32 2026-10-29) [darwin-arm64]
installed at /opt/homebrew/bin/byk
```

```bash title="--paths"
$ byk --paths

Python: /Users/coke/.byk/py-venv/.venv/bin/python
-----------------------------
CLI Home: /Users/coke/.byk
Cache: /Users/coke/.byk/cache
Alias: /Users/coke/.byk/alias
Plugins: /Users/coke/.byk/plugins
Python Venv: /Users/coke/.byk/py-venv
```

:::note
`Python` / `Plugins` / `Python Venv` 三行是旧版本留下的目录，byk 现在既不创建也不读取它们，输出暂时保持原样。
:::

## 执行别名

| 形式 | 说明 |
|------|------|
| `byk <key> [args...]` | 在合并后的别名空间里查找并执行 |
| `byk @file.key [args...]` | 精确执行**当前目录**某个文件里的别名 |
| `byk @@file.key [args...]` | 精确执行**全局目录** `~/.byk/alias/` 里某个文件的别名 |

```bash
byk dev                  # 合并空间查找
byk @run.build           # ./run.byk.json 的 build
byk @@work.deploy        # ~/.byk/alias/work.byk.json 的 deploy
```

精确语法只做文件路由，不做 fallback：文件不存在报 `Alias file not found: <file>`，key 不存在报 `Alias key not found in file @<file>: <key>`，两者都以退出码 1 结束。

## 程序接口 `__api__`

`byk __api__` 是给程序和编辑器插件用的只读接口：它**从不执行别名，从不写磁盘**，可以按任意频率调用。它不出现在 `-h` 里。

| 请求 | 输出 |
|------|------|
| `__api__ completion <shell>` | 补全注册脚本（zsh / bash / fish） |
| `__api__ complete <words...>` | 补全候选，一行一个 |
| `__api__`（无参） | 接口清单，JSON |

```bash
# 让 shell 认识 byk 的补全
source <(byk __api__ completion zsh)

# 查看接口清单
byk __api__
```

```json title="byk __api__"
{
  "requests": [
    {
      "name": "completion",
      "args": "<shell>",
      "description": "print the shell registration script (zsh|bash|fish)"
    },
    {
      "name": "complete",
      "args": "<words...>",
      "description": "print completion candidates, one per line"
    }
  ]
}
```

除上表三个请求之外没有别的参数位：未知请求、缺参数、不支持的 shell 都以退出码 1 结束。

### 补全是怎么接上的

`install.sh` 会往 `~/.zshrc`（或 `~/.bashrc`）写一行：

```bash
# byk shell completion
if command -v byk >/dev/null 2>&1; then source <(byk __api__ completion zsh); fi
```

这行把 Tab 事件转给 `byk __api__ complete`，由 byk 实时扫描别名后返回候选。手工写同样的行也完全等价。

## 匹配顺序

输入 `byk <word> ...` 时按以下顺序判断，第一个命中即返回：

1. `-h` / `-v` / `--paths` 等选项
2. `__api__` 隐藏接口
3. `@file.key` / `@@file.key` 精确执行
4. 合并空间里的别名

全部未命中时，输出 `Unrecognized command or alias: <word>`，并附上候选建议，退出码 1。
