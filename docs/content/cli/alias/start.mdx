# 快速开始

三分钟写出第一个别名文件。

## 快速入门

<Steps>

### 创建配置文件

在项目根目录创建 `run.byk.json`：

```json
{
  "dev": "pnpm dev",
  "build": "pnpm build",
  "deploy": {
    "$cmd": "deploy --env {env}",
    "$interactive": true
  }
}
```

### 精确执行

```bash
byk @run.dev
byk @run.build
byk @run.deploy            # 交互：先问 env，确认后再执行
```

本地文件的默认优先级是 `-1`，**不参与合并**——它只属于这个项目，所以用 `@文件.key` 指定。这样 `byk build` 不会因为你在某个目录下而突然变成别的意思。

### 想让它全局可用

两种方式，按需选择：

<Tabs>
<Tab label="放进全局目录">

```bash
cp run.byk.json ~/.byk/alias/
byk dev
```

`~/.byk/alias/` 下的文件默认优先级 `0`，直接进合并空间。

</Tab>
<Tab label="声明优先级">

```json title="run.byk.json"
{
  "$priority": 0,
  "dev": "pnpm dev"
}
```

`$priority >= 0` 的文件会参与合并，`byk dev` 直接可用，同时保留「文件就在项目里」的组织方式。

</Tab>
</Tabs>
